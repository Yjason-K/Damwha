## 앱 실측 (개발 모드, 전체 화면 Chrome Google Meet)

사용자가 직접 조작했다. 아래 항목이 모두 정상이었다.

- 녹음을 시작하면 상단 가운데가 비고 오른쪽 위에 알약이 뜬다.
- 알약 본문을 누르면 녹음이 멈추지 않고 회의 화면이 열린다. Meet으로 돌아와도 알약이 그대로 있다.
- 호버하면 `중지`가 나오고, 누르면 녹음이 멈춘다.
- 옮긴 위치가 다음 녹음에서도 유지된다. 전체 화면에서 맨 위·맨 아래에 둔 경우도 같다.
- 빠르게 드래그해 창 밖에서 놓아도 알약이 접힌다.
- 조작한 뒤 Meet의 `⌘D`가 먹는다.
- 화면 공유 때 참가자에게 알약이 보이지 않는다.
- 호버로 늘고 줄 때 끊김이나 잔상이 없다.

## 스펙과 달라진 것

- **알약 크기:** 88×32, 호버 140×32. 스펙 §4.1의 스파이크 값(92·144)과 다르다. 첫 실측에서 오른쪽에만 빈 자리가 몰려 어색했다. 그래서 폭을 줄이고 점과 시간을 가운데에 두었다.
- **호버 애니메이션:** 첫 실측에서 호버가 뚝뚝 끊겼다. 원인은 둘이었다. `중지`가 `display`로 바로 나타났고, 창 크기도 애니메이션 없이 바뀌었다. 지금은 호버 때만 macOS 창 애니메이션(`setBounds(r, true)`)으로 늘고 줄며, `중지`는 투명도 150ms로 바뀐다. 시스템의 "동작 줄이기"가 켜져 있으면 둘 다 끈다.
- **`중지` 위치:** 최종 리뷰에서 처음 구현의 문제가 나왔다. `중지`가 늘어난 창의 오른쪽, 곧 평소 클릭 자리에 떠서 회의를 열려는 클릭이 녹음을 끊었다. 지금은 `중지`가 늘어난 왼쪽 자리에만 있다.
- **중지 실패:** 정지가 실패하면 알약과 카드의 버튼을 다시 푼다. 스펙에는 없던 동작이다. 스펙의 "멈출 경로를 남긴다"를 지키려고 더했다.

## 남은 것

- `1:02:34`처럼 1시간이 넘은 시간 표시는 실측하지 않았다. 최종 리뷰의 측정으로는 시간 영역이 약 70px이라 들어간다.
- 실측 중 녹음이 마무리되지 않는 문제를 만났다. 이 변경과 무관한 worker 버그로 확인했다. 미리보기가 30초 넘게 밀리면 건너뛰기 무한 루프에 빠진다. [#72](https://github.com/Yjason-K/Damwha/issues/72)로 따로 고친다.
- 정지가 실패한 뒤 다시 누르면 서버에 정지를 보내지 않고 `stopped`로 끝날 수 있다. fe 녹음기가 첫 정지 Promise를 기억하기 때문이다. 이 변경 전부터 있던 문제다.
- 패키징한 서명 앱에서는 재지 않았다.
