## 실측 요약

- **T0 Zoom** (`us.zoom.xos`): 음소거해도 입력 유지, 미리보기에서는 입력 없음, 회의 종료 직후 입력·출력 꺼짐. `autoStop: true`.
- **T0 백그라운드 시작** (Electron 44.3): 창이 뒤에 있거나 최소화돼도 `getUserMedia`와 `AudioContext`가 동작했다. 제스처 없이도 `running`이라 `autoplayPolicy`는 넣지 않았다.
- **T0 패널:** `type: "panel"` + `showInactive()`는 입력을 끊지 않고, 클릭을 받아도 포커스를 가져가지 않았다.
- **T0 서명:** Developer ID·hardened runtime 앱의 자식 헬퍼가 권한 창 없이 Zoom을 감지했다. CPU 0.1%.
- **dev 앱:** 시험 회의 `mtg_115`(57초, 전사·요약 완료), `mtg_116`, `mtg_117`, `mtg_118`(모달 시험).
- **서명 앱:** `mtg_119`. 시험 음성이 시스템 오디오로 전사됐다.
- **서명 앱 추가 실측:** `mtg_121`(전체 화면 Zoom, 52초에 `device_ended`), `mtg_122`(Zoom 음소거 약 3분 40초, 총 3분 59초), `mtg_123`(임시 Chrome 프로필의 시험 페이지, 34초). 모두 Zoom 회의 또는 시험 페이지로 재현했고 실제 Google Meet은 아니다.

취소한 앱 종료 뒤 헬퍼 재기동과 이후 자동 종료는 실측으로 통과했다. 전체 화면 Zoom 위에서 카드를 눌러 녹음을 시작했다(`mtg_121`). 잠자기 복귀, 외장 모니터, 실제 Google Meet, 실제 화면 공유, Teams는 **미실측**이다. `setContentProtection`은 스크린샷과 `screencapture`에서 카드가 빠지는 것까지 확인했고, Zoom 화면 공유 자체는 재지 않았다. 같은 이유로 실제 창의 카드는 캡처하지 못했다. 카드 모양은 `detect.html`을 Chromium 360×84에 그려 확인했다(`docs/images/2026-11-01/`). 실제 창의 시스템 그림자는 미확인이다.

## 구현 중 발견

- **기존 버그 수정:** 녹음을 멈출 때 시스템 오디오 스트림이 닫힌 뒤 도착한 데이터로 main에 uncaught 오류 창이 떴다(`system-audio-protocol.ts`, `5ee542d`). 수정 뒤 재현되지 않았다.
- **첫 사용 한계:** 서명 앱이 처음 시스템 오디오 권한을 물을 때 헬퍼의 5초 준비 상한이 먼저 끝나 카드 시작이 실패한다. 이 실패에는 억제를 걸지 않아, 허용한 뒤 입력이 이어지면 끝 카드가 닫히고 카드가 다시 뜬다. 허용 뒤 복구는 테스트로만 확인했다.
- **`setVisibleOnAllWorkspaces`의 Dock 소실:** 기본 동작이 프로세스 종류를 바꿔, 카드가 한 번 뜨면 담화가 Dock에서 사라지고 `회의 보기`도 활성 앱을 못 바꿨다. `skipTransformProcessType: true`로 고친 뒤 서명 앱(`mtg_120`)에서 카드 뒤에도 일반 앱으로 남고, `회의 보기`가 회의 화면을 열며 담화를 활성 앱으로 올리는 것을 실측했다. 이 옵션을 켠 뒤에도 전체 화면 Zoom 위 카드는 동작했다(`mtg_121`).
- **렌더러가 끝내 멎으면:** 응답 없음 3회 뒤 `stop`을 건다. 렌더러가 회복하지 않으면 카드는 `녹음이 끊겼어요`로 끝나도 마이크가 앱 종료까지 살아 있을 수 있다.
- **입력 장치 전환으로 녹음 끊김:** 녹음 52초에 마이크 트랙이 끝나 `device_ended`로 마감됐고 Zoom 회의는 계속됐다(`mtg_121`). 약 3초 전 AirPods 활동이 있었고 끊긴 뒤 기본 입력이 AirPods였다. 장치 전환이 원인이라는 것은 정황이며 재현은 안 했다. 그 시점 이후는 녹음되지 않는다. [#69](https://github.com/Yjason-K/Damwha/issues/69)로 넘겼다.
- **창 닫기 정지의 끝 카드:** 카드로 시작한 녹음이 창 닫기로 깨끗하게 멈춰도 `녹음이 끊겼어요`가 뜬다. 끊겼다고 말하는 쪽이라 안전하다. §4.6과 함께 후속으로 고친다.
- **미해명 종료 1건:** 서명 앱 첫 실행 약 1분 뒤 앱과 자식이 동시에 SIGTERM을 받고 종료됐다. 카드 30초 시간 초과로는 재현되지 않았고 이후 재현도 없었다. 외부 신호로 보지만 원인은 확인하지 못했다.

## 스펙과 달라진 점

- 대상 앱은 Zoom·Chrome이다. Teams는 뺐다.
- 헬퍼는 오류 줄을 쓰고 끝난다. 재기동이 전체 스냅숏을 보장한다.
- 잠자기·창 닫기·앱 종료 일시 중단 중에도 카드 녹음 표시는 유지한다.
- `autoplayPolicy`는 넣지 않았다.
