# 어떻게 잰 것인가: build.sh all 을 마친 bundle/python 을 bundle/pytrial 로

# 파이썬은 -B 로 부른다 — .pyc 를 남기면 그 안에 pytrial 경로가 박혀 되돌린
# 뒤 G1 결과를 바꿔 버린다. (그 자체가 재배치의 또 다른 얼굴이다.)
#
# 격리 대상 밖의 관찰이다 — 여기서 보려는 것은 '무엇이 깨지는가'이지 격리가 아니다.
