# ================================================================
# V9 — grep -c 의 exit 코드
# ================================================================
#
# 표의 기대 칸은 `0` 이다. 이것은 **출력**이고, 그 값이 실제로 나온다.
# 그런데 grep -c 는 매치가 0건이면 exit 1 이다. 즉 이 행은 "기대대로일 때
# exit 1, 어긋날 때 exit 0" 이라 exit 으로 판정하면 뒤집힌다.
#
# 처음 돌렸을 때는 출력이 `1` 이었다. 드라이버의 모듈 docstring 이 smoke
# 스크립트를 쓰지 않는 이유를 설명하며 그 라이브러리 이름을 한 번 적었기
# 때문이다. 검사가 리터럴 문자열 개수를 세므로 설명문도 세어진다. 이름을 빼고
# 뜻만 남기도록 고쳤고, 그 사정을 드라이버 docstring 에 적어 두었다.
#
