  기존 DB 스키마, 잡 페이로드, 소유권 가드는 유지한다.

## 목표와 완료 기준

1. 두 Whisper 어댑터, 최종 발화 조립, 실시간 미리보기에서 모델이 반환한
   단어의 원래 경계를 보존한다. 일본어·중국어와 공백을 사용하는 언어를 검증한다.
2. 현재 처리 버전의 유효 발화가 없으면 모델 서버 시작과 요약 요청을 생략하고
   `topics`, `segments`, `suggested_tags`가 모두 빈 배열인 완료 결과를 저장한다.
3. 빈 입력에 세그먼트를 반환하도록 설정한 모델 대역도 호출하지 않는다.
   기존 오류와 과거 요약은 정상 저장 경로에서 지워지고 잡은 진행률 100으로 완료된다.
4. 수정 전 실패와 수정 후 성공을 기록하고, 가짜 모델 출력으로 검증한 결과와
   실제 음성·모델로 측정하지 않은 내용을 구분한다.

## 범위

워커 내부 전사·요약 처리와 관련 테스트, 작업 기록만 변경한다.
요약 작업을 큐에 넣는 API/DB 계약은 유지하며 빈 작업도 기존 완료 상태를 남긴다.
언어별 공백 추측 대신 원본 단어 문자열을 보존한다.
