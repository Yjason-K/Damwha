# 회의 목록 드롭존과 결정·할 일 요약 설계

**작성일:** 2026-10-05
**선행:** `feat/meeting-folders` @ `2daabeb` (PR #54 병합 지점)
**대체:** `2026-10-04-folder-meeting-list-design.md`의 빈 상태 문구(`아직 회의가 없어요.` / `이 폴더에 회의가 없어요.`) — 빈 목록은 드롭존이 대신한다.
**범위:** `/meetings`와 `/folders/:folderId` 카드 목록 위에 녹음 파일 드롭존과 `최근 결정` / `진행 중인 할 일` 요약 카드를 둔다.

## 1. 목표와 성공 기준

목록 화면에서 바로 새 회의를 시작하고, 쌓인 결정과 할 일을 회의를 열지 않고 훑는다.

- 드롭존은 항상 목록 위에 있다. 회의가 없으면 크게(빈 상태), 있으면 한 줄로 줄인다.
- 파일을 놓거나 `파일 선택하기`(`⌥U`)로 고르면 바로 올리지 않는다. 그 파일을 채운 새 회의 모달이
  열리고, 옵션(일시·제목·폴더·참석자 수·후속 처리)을 고른 뒤 올린다. 폴더는 보고 있던 폴더로 시작한다.
- `실시간 녹음 시작`은 새 회의 모달을 실시간 녹음 탭으로 연다. 옵션을 고른 뒤 녹음한다.
- 오디오가 아닌 파일은 모달을 열지 않고 토스트로 알린다.
- 회의가 하나 이상이면 드롭존 아래에 요약 카드 두 개를 둔다.
  - `최근 결정 N건`: 열린 결정 최근 2개. 회의 제목과 근거 시각 링크(`/meetings/:id?u=`).
  - `진행 중인 할 일 N건`: 열린 할 일 최근 2개. 담당자(화자 색 아바타)와 기한 배지(`D-2 (4월 2일)` /
    `D-Day` / `D+3 (…)`; 오늘·지난 기한은 위험색).
  - 폴더 화면에서는 그 폴더 회의의 항목만 세고 보여 준다. `모두 보기`는 전역 렌즈 대시보드로 간다.

## 2. 설계

### 2.1 BE — `GET /lenses`

- `folder_id` 필터를 추가한다(`^fld_[1-9][0-9]*$`, 형식이 틀리면 400). `m.folder_id`로 거른다.
- 응답에 `total`(커서와 상관없는 같은 필터의 전체 건수)을 더한다. 기존 필드는 그대로다.

### 2.2 FE

- `features/lens/api/lenses.ts` `useLensOverview(kind, folderId)` — `limit=2`, `completion_status=open`.
  쿼리 키는 `["lens-overview", …]`다. `["lenses"]` 아래에 두면 완료 토글의 낙관적 갱신이 이 캐시를 무한
  목록 모양으로 다뤄 깨진다. 완료 토글은 이 키도 무효화한다.
- `features/lens/ui/lens-overview.tsx`, `features/lens/lib/due-day.ts`.
- `features/meeting/ui/meeting-dropzone.tsx`.
- `NewMeetingDialog`에 `initialSource`/`initialFile`을 더한다. 열리는 순간에만 적용하고, 탭은 로컬
  저장소에 기억하지 않는다.
- `pages/meeting-list.tsx`가 자기 `NewMeetingDialog`를 들고 드롭존과 잇는다.

### 2.3 하지 않는 것

- 스크린샷의 색 막대 장식은 넣지 않는다 — 화자 팔레트를 장식에 쓰지 않는다(DESIGN.md).
- `mp4 지원 (최대 2GB)` 문구는 쓰지 않는다. 서버는 `audio/*`만 받고 기본 한도는 1GB다.
- `모두 보기`의 폴더 필터 — 전역 대시보드에 폴더 필터가 없다.
