# CLI · MCP 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 담화 데스크톱 앱에 `damwha` CLI와 stdio MCP 서버(`damwha mcp`)를 더하고, 앱 설정에서 원클릭으로 설치·Claude Code·Codex 등록을 한다.

**Architecture:** 새 워크스페이스 패키지 `cli/`가 HTTP 클라이언트·CLI·MCP 서버를 담고 esbuild로 단일 CJS를 만든다. desktop이 그것을 `Resources/cli/`로 싣고, API 기동 때 `<userData>/api.json`(포트·nonce)을 쓴다. be는 MCP가 필요로 하는 읽기 API 넷과 status 단계, 그리고 데스크톱 전용 `/api/integrations/*`를 더한다. fe 설정 화면이 그 API로 설치를 수행한다.

**Tech Stack:** Node 22, TypeScript, `@modelcontextprotocol/sdk`, esbuild, NestJS 10(jest+testcontainers), Electron 44(vitest), React 19(vitest+jsdom), Astro 7.

**Spec:** `docs/superpowers/specs/2026-10-20-cli-mcp-design.md`

## Global Constraints

- CLI·MCP는 HTTP API(`/api`)만 쓴다. Postgres·스토리지 직접 접근 금지 (spec §1 반목표).
- 열거형 값(`PRESET_NAMES`, `WHISPER_MODELS`, `DEVICES`, STT 언어)은 `@damwha/contracts`에서만 가져온다. 목록을 다시 적지 않는다.
- MCP 도구 이름·설명·입력 스키마는 영어. 사용자용 메시지는 앱 UI 언어(ko/en) (spec §2.4).
- 회의 유래 문자열은 MCP 응답에서 `untrusted_meeting_data` 아래에만 둔다 (spec §2.2).
- `complete_lens`는 elicitation `accept`일 때만 `POST /api/lenses/:id/complete` (spec C2, §2.3).
- 연동 API는 `DAMWHA_CLI_LAUNCHER`가 있고 `HOST`가 loopback이고 `DEMO_READ_ONLY !== 'true'`일 때만. 아니면 404 (spec §2.7).
- 명령 실행은 `execFile`, 고정 인자 배열, 타임아웃 15초, 출력 64KB 상한 (spec §2.7).
- 종료 코드: 0 성공, 1 사용·API 오류, 2 미실행·준비 중, 3 `--wait` 중 단계 실패 (spec §2.4).
- 전사 페이지 `limit` 기본 200, 최대 500. 회의 목록 페이지는 쿼리가 없으면 기존 응답 그대로 (spec §2.2).
- be 테스트는 `be/test/`에 둔다. e2e는 `/api` prefix 없이 부른다. desktop 테스트는 `desktop/tests/`가 `src/`를 따른다. fe 테스트는 같은 폴더에 `*.test.tsx`.
- `npm install` 금지, 의존성 추가는 루트에서 `pnpm --filter <pkg> add`.

## Review Focus

1. **앱을 옮기거나 업데이트한 뒤의 CLI 링크** — 대상이 사라진 담화 링크는 설치 버튼 한 번으로 고쳐져야 한다. Task 7 `replaces dangling damwha link` 테스트.
2. **처리 중에 요약·렌즈를 꺼둔 업로드의 `--wait`** — 꺼둔 단계를 기다리며 멈추면 안 된다. Task 4 `stage is skipped when followup deferred`, Task 10 `wait ends when skipped stages remain`.
3. **긴 회의(발화 수천 개)의 전사 조회** — MCP 응답이 페이지 한도를 넘지 않아야 한다. Task 3 `caps limit at 500`.
4. **본인 화자가 없을 때 `mine`** — 빈 목록이 아니라 안내 오류가 나와야 한다. Task 11 `list_lenses mine without is_me errors`.
5. **포트는 같은데 다른 프로세스가 듣고 있음(앱 재시작, 낡은 api.json)** — "준비 중"/"미실행"으로 판정되어야 한다. Task 8 `nonce mismatch is starting`.
