# 이슈 102·103 구현 계획

**Spec:** [설계](../specs/2026-11-25-issues-102-103-design.md)

1. 현재 `dev`에서 별도 워크트리를 만들고 이슈의 과거 근거를 현재 코드와 대조한다.
2. #102: 두 STT 어댑터와 발화 조립·실시간 경로를 추적한다. 원래 공백과
   무공백 일본어·중국어 경계를 검증하는 실패 테스트를 만든 뒤 원인을 수정한다.
3. #103: 실제 Postgres와 잡 디스패치를 사용해 빈 입력에서 호출되는 LLM과
   불필요한 서버 시작을 재현한다. 유효 입력 확인 뒤에만 모델 실행을 시작하고,
   빈 결과도 공통 저장 경로와 기존 소유권 가드를 통과하도록 수정한다.
4. 관련 테스트와 워커 회귀 검사를 실행하고 변경 파일의 린트·형식을 확인한다.
5. 실행 결과와 미검증 범위, 워크트리·브랜치를 결과 문서와 최종 보고에 남긴다.
