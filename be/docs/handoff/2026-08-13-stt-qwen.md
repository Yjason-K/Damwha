## 3. 다음에 할 수 있는 일

우선순위 순. 각 항목의 배경은 [백로그](../backlog.md)에도 등록해 뒀다.

### A. 루프 발생의 비결정성 규명 (미해결, 백로그 등록됨)

지금 수정은 **결과를 걷어낼 뿐 발생을 막지 못한다.** 같은 파일·같은 파라미터로도 매 run
다른 span에서 터진다 — 격리 호출 72회에서 0건, 207-clip 배치에서 run당 1–5건.
MLX 수치 비결정성을 의심했지만 확증하지 않았다.

- 확인 안 해본 것: 같은 배치를 CPU(faster-whisper)로 돌리면 결정적인가? 그렇다면
  MLX 쪽이 맞다.
- 재현하려면 필터를 우회해야 한다 — `drop_repetition_loops`를 거치기 전 단어를 봐야
  하므로, 어댑터를 쓰지 말고 `mlx_whisper.transcribe`를 직접 호출하는 진단 스크립트가
  필요하다(위 표의 `diag_fix.py` 형태).

### B. Qwen3-ASR 도입 판단 종결 (백로그 등록됨)

측정은 끝났고 결론은 "근거 약함"이다. **판단만 남았다.** 남은 고려사항 하나: qwen17은
3회 모두 출력이 완전히 동일했고(12,293자, CER 26.19%) turbo는 2.9%p 퍼진다. 이 저장소가
payload 재현성을 설계 가치로 두므로 무의미한 차이는 아니나, 3회로 결정성을 단정할 수
없다. 재검토 트리거: ForcedAligner가 불필요해지거나 다화자 성능이 개선될 때.

### C. 참조 기반 회의 eval을 정식 도구로 (선택)

`eval_stt.py`는 `--json3`(유튜브 자막)만 참조로 받는다. Clova Note 전사를 참조로 받는
경로를 추가하면 실제 회의로 CER을 재는 것이 일회성 스크립트가 아니게 된다. 위 정제 규칙
5줄이면 된다. **다만 지금 당장 필요하지 않다** — 필요해질 때 하면 된다.

## 4. 재시작 명령

```bash
cd <repo>/worker
uv sync --extra models          # 실모델 (mlx-whisper / pyannote / ECAPA / silero)
uv run pytest -q                # 311개 통과해야 정상
uv run ruff check .

# 강연 오디오 CER (참조 있음)
uv run --with jiwer python scripts/eval_stt.py \
  --wav <강연>/audio16k.wav --json3 <참조>.ko.json3 \
  --outdir /tmp/out --runs turbo --language ko
# 기대값: CER 5.07–5.27% (이 범위가 재현 오차)

# Qwen까지 재려면 --with를 하나 더
uv run --with jiwer --with mlx-audio python scripts/eval_stt.py \
  --wav ... --json3 ... --outdir ... --runs turbo,qwen17,qwen06
```

수정이 살아있는지 빠르게 확인하려면 회의 오디오를 프로덕션 경로로 한 번 돌리고
`CON`/반복 토큰이 없는지 보면 된다. 수정 전에는 run당 1–5개 span에서 터졌다.

## 5. 알아두면 좋은 함정

- **`--full-file`은 "가드 없음"이 아니다.** clip 가드만 끄고 decode 파라미터 가드는
  어댑터 모듈 상수라 계속 켜져 있다. SMOKE.md 표의 "가드 없음" 행(3.98%)은 어댑터
  상수를 손으로 고쳐야 나오는 값이라 현재 플래그로 도달할 수 없다.
- **`no_speech_threshold=None`을 다시 시도하지 말 것.** 반복 판정은 살아나지만 무음
  스킵도 함께 꺼져 강연 CER이 5.07% → 8.82%로 악화된다. 측정해서 기각한 안이고,
  이유는 `pipeline/stt_repetition.py` 모듈 주석에 남겼다.
- **`devices.stt=cpu`는 회피로가 아니다.** `faster_whisper/transcribe.py:1513, 1223`에
  같은 upstream 로직이 있다.
- **참조 전사 두 개(유튜브 자막·Clova Note) 모두 ASR 출력이다.** 절대 정확도가 아니라
  상대 비교로만 읽는다. 회의 CER 26%는 "26% 틀렸다"가 아니라 "다른 ASR과 26% 다르다"는
  뜻이다.
